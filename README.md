## About Huzur Mostar

**Huzur Mostar** is a beloved flower shop located in the heart of Mostar, Bosnia and Herzegovina. The name "Huzur" means peace and tranquility - a philosophy that flows through every arrangement we create. We believe that flowers have the power to bring harmony, joy, and meaningful moments to people's lives.

Whether you're celebrating a special occasion, expressing love, or simply brightening someone's day, Huzur Mostar is here to craft the perfect floral experience for you.

## Deployment

This website is automatically deployed and maintained through a modern CI/CD pipeline:

- **Hosting**: [Netlify](https://www.netlify.com/) - Fast, global CDN delivery
- **Continuous Integration**: GitHub Actions runs automated tests on every code change
- **Automatic Deployments**: Every merge to the main branch triggers a new production deployment
- **Preview Deployments**: Pull requests get their own preview URLs for review

The site is live at: **[huzurmostar.ba](https://huzurmostar.ba/)**
